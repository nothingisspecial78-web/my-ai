# 7. DATABASE SECURITY

Security is mandatory.

Enable Supabase Row Level Security.

Users must only be able to access their own data.

Implement policies for:

### profiles

A user can:

* Read their own profile
* Update their own profile

### conversations

A user can:

* Create their own conversations
* Read their own conversations
* Update their own conversations
* Delete their own conversations

### messages

A user can:

* Create messages in conversations they own
* Read messages from conversations they own
* Delete their own messages if required

Never trust:

```text
user_id
```

sent from the browser.

Derive the authenticated user from the server-side session.

Never use the Supabase service-role key in client-side code.

       ↓

* Timeout
* Rate limits
